🎯 KEY FEATURES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

✅ 6 Scale Modes
   • ROUND_OUTER - Circular scale with ticks on outside (default)
   • ROUND_INNER - Circular scale with ticks on inside
   • HORIZONTAL_TOP - Horizontal with ticks on top
   • HORIZONTAL_BOTTOM - Horizontal with ticks on bottom
   • VERTICAL_LEFT - Vertical with ticks on left
   • VERTICAL_RIGHT - Vertical with ticks on right

✅ Tick Configuration
   • Minor ticks (count, width, length, color, radial offset)
   • Major ticks (stride, width, length, color, labels)
   • Label show/hide with gap configuration

✅ Colored Sections
   • Multiple independent sections
   • Range configuration (start/end)
   • Color and width per section
   • Dynamic updates via automation

✅ Range & Rotation
   • Configurable min/max values
   • Negative range support
   • Rotation angle (0-360°)
   • Angle range coverage
   • Default: 270° coverage, 135° rotation (speedometer style)

✅ Styling Parts
   • MAIN - Background and scale line
   • INDICATOR - Major ticks and labels
   • ITEMS - Minor ticks

✅ Automation
   • lvgl.scale.update - Update scale configuration
   • lvgl.scale.section.update - Update section ranges and colors

3. Read SCALE_WIDGET_README.md for detailed documentation

6. Use colored sections for zones (safe/warning/danger)
7. Typical rotation: 135°, angle_range: 270° for speedometer style
8. Major tick stride of 5 works well for most scales
9. Make section width larger than tick width for visibility
10. Test with different modes to find the best fit for your use case
