TECHNICAL IMPLEMENTATION
───────────────────────────────────────────────────────────────────────────────

Widget Type: lv_list_t (LvCompound)
Parts: MAIN, SCROLLBAR
Dependencies: btn, label

Schema:
  - items: List of button/text items
  - Each item:
    - type: "button" or "text" (required)
    - text: string/lambda (required)
    - src: image (optional, for button icons)

Code Generation:
  - Direct LVGL API calls using lv.list_add_button() and lv.list_add_text()
  - Proper text processing with lv_text.process()
  - Image processing with lv_image.process()
  - NULL handling for buttons without icons
